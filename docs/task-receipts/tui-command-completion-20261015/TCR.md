# TUI 命令自动补全 TCR

## 授权与范围

用户已通过本轮 GUI/TUI 视觉验收，要求补充 TUI 命令自动补全，再同步远端更新并分组提交本地保存点。

修改限于 TUI 命令候选、键盘接线、候选渲染和中英文提示。沿用已有命令执行入口，不改变 Session、Kernel、权限或命令参数语义。

## 测试变更必要性

现有测试覆盖插件、模型和会话选择器，尚不能证明斜杠命令的筛选、补全与执行之间的边界。新增测试加入现有 `shells/tui/src/app.rs` 单元测试模块，复用 `TuiApp` 与 ratatui `TestBackend`，由 `cargo test --workspace` 自动执行，不新增测试 runner 或变更 profile。

## 最小覆盖

1. `/` 和命令前缀打开并筛选候选；Tab/Enter 接受候选只写入输入框，不执行命令。已有完整命令及其参数仍由原提交入口处理。
2. 上下选择、首尾循环和候选滚动保持选中项可见；中英文、小尺寸终端中的候选不挤掉输入光标。
3. Esc 收起候选并保留草稿；继续编辑可重新打开；清空、提交或切换会话后不残留候选。
4. 普通文本、命令参数和多行粘贴不误触发补全；既有插件/模型/会话选择器保持优先级。
5. 运行容器内 `bash ./test.sh required`，以及正式 TUI 构建入口。既有断言、注册和必验范围保持不变。

## 证据边界

单测与构建分别记录；命令补全不会自动选择权限回复、发送消息或产生 Provider 请求。远端同步和本地提交不代表推送或发布。
