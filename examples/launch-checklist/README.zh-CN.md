# 发布清单

[English](README.md) · [所有示例](../README.zh-CN.md)

一个可以直接操作的 Computer Use 示例项目：四项发布任务、进度统计、筛选和浏览器本地保存。直接打开 `index.html`，无需服务器和依赖。

在 Achbit 中将本目录打开为项目，选择支持图片输入的模型，然后发送：

> 使用 Computer Use 在内置浏览器中打开 index.html。重置清单，勾选 “Build the application” 和 “Run the checks”，确认页面显示 2 / 4 和 50%。使用 Completed 筛选检查两项已选任务，然后切回 All tasks，重载页面，确认勾选仍然保留。截取最终页面并报告实际观察结果。不要编辑项目文件。

英文提示词见 [prompt.en.txt](prompt.en.txt)。点击 **Reset checklist** 可再次体验。

这个项目演示文件预览 → 页面观察 → 交互 → 重载 → 可视验证。勾选框是示例任务，勾选本身不会执行应用构建或测试。
