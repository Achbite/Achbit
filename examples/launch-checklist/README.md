# Launch checklist

[简体中文](README.zh-CN.md) · [All examples](../README.md)

A small Computer Use project: four release tasks, progress counters, filters, and browser-local persistence. Open `index.html` directly; no server or dependencies are required.

Open this directory as a project in Achbit, select a model with image input, and send the prompt below:

> Open index.html in the built-in browser using Computer Use. Reset the checklist, check “Build the application” and “Run the checks”, and verify that the page shows 2 / 4 and 50%. Use the Completed filter to inspect the two selected tasks. Return to All tasks, reload, and confirm that both selections persist. Capture the final page and report what you observed. Do not edit the project files.

The same prompt is in [prompt.en.txt](prompt.en.txt). Use **Reset checklist** to repeat the exercise.

The example exercises file preview → page observation → interaction → reload → visual verification. The checkboxes represent this demo's tasks; ticking them does not run an application build or test suite.
