Chromium、Firefox、WebKit 支持范围对照
维度 Chromium Firefox WebKit
构建来源 默认使用开源 Chromium 构建；版本领先品牌浏览器，Google Chrome N 时已支持 Chromium N+1。 匹配近期 Firefox Stable 的构建；依赖 Playwright 的补丁。 取自 WebKit main 分支，常早于 Apple Safari 集成这些更新。
品牌版 / 通道 可驱动机器上已安装的 Chrome、Edge；品牌浏览器不默认安装。当前版本明确支持 Stable、Beta，另有 dev / canary 通道可用。 不支持品牌版不能改用系统安装的 Firefox 代替。 不支持品牌版不能改用 Safari 代替，应使用最新 WebKit 构建。
版本节奏 领先 Stable 数周，适合提前发现下一版 Chrome / Edge 的回归。 匹配近期 Firefox Stable 构建。 领先 Safari 的集成节奏，为浏览器升级问题留出反应时间。
平台相关差异 开源构建不含 Chrome / Edge 打包的全部编解码器；企业浏览器策略可能影响启动与控制。 媒体编解码等平台相关能力在 Linux、macOS、Windows 间差异明显。 同样随操作系统变化；Linux CI 成本低，macOS 最接近 Safari（如视频播放）。
验收关注
建议		 先确认本次用的是开源 Chromium 还是 chrome / msedge 通道；headless 用例明确实现模式；编解码相关用例补跑品牌通道。 只用 Playwright 提供的构建；在目标用户所在 OS 上复跑平台相关用例，不只看 CI。 视频类用例在 macOS 上复核；报告里不要写成“Safari 已通过”。

前四行是 Playwright 文档的陈述；“验收关注”是本速查表据此给出的操作建议，不是官方结论。

安装默认浏览器 npx playwright install
只安装 WebKit npx playwright install webkit
连同系统依赖安装（CI） npx playwright install --with-deps chromium

默认缓存位置（macOS）：~/Library/Caches/ms-playwright。文档示例体积：Chromium 约 281M、Firefox 约 187M、WebKit 约 180M，实际以本机为准。
