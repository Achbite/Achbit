# Product operations reference

Product behavior is documented separately from task guidance. Read `operations.md` in `productDocsPath` with the shell for tool scope, validation, model/context accounting and settings. Use `execution-environments.md` for native Windows and WSL configuration, and `model-services.md` for model connections, Coding Plans, image input, usage pricing and optional child context/compaction configuration. For automatic context management (Settings > Agent behavior), task-boundary timing and historical readback, read the Context management sections of these documents; do not infer behavior from a cached usage percentage.
