# Product operations reference

Product behavior is documented separately from task guidance. Use `doc.read` with `name="operations.md"` for tool scope, validation, model/context accounting and settings. Use `name="execution-environments.md"` for native Windows and WSL configuration, and `name="model-services.md"` for model connections, Coding Plans, image input, usage pricing and optional child context/compaction configuration. For automatic context management (Settings > Agent behavior), task-boundary timing and historical readback, read the Context management sections of these documents; do not infer behavior from a cached usage percentage.
