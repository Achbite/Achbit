# Document creation

Choose the requested format for the actual reader and delivery context. Author the complete content in the selected format. Reuse the supplied templates where they fit and preserve their notices. Use the rendering and presentation mechanism supported by the current environment. Check the returned artifact and, when layout matters, inspect the rendered output. Report a rendering error with its source and identify which format and checks were delivered.

Choose [layout and typography](references/design.md) for visual decisions or [output formats](references/formats.md) for self-contained HTML, Markdown and Typst. Use the [HTML template](assets/document.html) or [Typst template](assets/document.typ) when it suits the content. For an inline diagram see [Mermaid diagrams](references/inline-diagrams.md).
